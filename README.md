# Maram Saidi — IoT Engineering Portfolio

> Personal portfolio website for Maram Saidi, 4th-year Engineering Student specializing in IoT & Embedded Systems.

🔗 **Live:** [MaramSaidii.github.io/portfolio](https://MaramSaidii.github.io/portfolio)

---

## ✨ Features

- **Animated hero** — hexagonal photo frame with dual SVG border glow, orbit ring, floating tech cards, live IoT sensor data simulation
- **Particle network** — canvas-based background with animated particle mesh and globe
- **3D dot-mesh background** — perspective wave terrain with glowing dots
- **Typing role effect** — cycles through role titles with typewriter animation
- **Mouse trail** — cyan/purple particles follow the cursor
- **Glass navbar** — frosted glassmorphism pill with active underline
- **Projects section** — featured AgriNova card + AstroQuest + Smart Robot Arm + ESPRIT_SR with image sliders
- **Cursor reveal** — contact section background switch on mouse move (torch effect)
- **Scroll animations** — staggered reveal on every section
- **Dark deep-navy theme** — rich blue palette with cyan/purple/pink accents

## 🏃 Run Locally

No build step needed — pure HTML/CSS/JS.

```bash
# Just open the file
start index.html        # Windows
open index.html         # macOS
```

Or use a local server for best results:
```bash
npx serve .
# → http://localhost:3000
```
